# Final Data Science Project

## Student Performance Analysis and Grade Prediction

### Project Overview
An end-to-end data science project using the UCI Student Performance dataset. The project explores student performance and builds a machine learning model to predict final grades.

### Objectives
- Inspect and clean the dataset.
- Perform exploratory data analysis.
- Visualize grade distributions and feature relationships.
- Train a Random Forest Regression model.
- Evaluate predictions using MAE, RMSE, and R².
- Explore feature importance.

### Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

### Machine Learning
The Random Forest Regression model uses previous grades and other student information to predict the final grade (G3). The data is divided into training and testing sets for evaluation.

### Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

### Dataset Source
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/320/student%2Bperformance

### How to Run
1. Open the notebook in Google Colab.
2. Download the `student-mat.csv` file from the dataset source.
3. Upload the CSV file when prompted.
4. Run the notebook cells in order.

### Disclaimer
This project is for educational purposes. Predictions are estimates and should not be treated as guaranteed student outcomes.
